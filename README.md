# Αμοιβή Live

Μετρητής αμοιβής βάρδιας για Android, με widget στην αρχική οθόνη.

- Έναρξη / Τέλος με επιλογή ώρας από ρολόι
- Live ποσό με βάση την αμοιβή ανά ώρα (προεπιλογή 8 €)
- Έξοδα βάρδιας και καθαρά
- Ιστορικό βαρδιών (παρατεταμένο πάτημα για διαγραφή)

Το APK χτίζεται αυτόματα με GitHub Actions και ανεβαίνει στα **Releases**.
